|---|---|---|---|---|---|---|

## 三、 不圆度统一计算公式与量纲对齐

为彻底解决“绝对差值 mm”与“百分比不圆度 %”的历史口径冲突，边缘端（Edge Agent）执行双重归一化：

1. **百分比不圆度（平台指标标准口径，上报平台 `OVALITY` 指标）**：
   $$\text{Ovality}_{\%} = \frac{200 \times |D_X - D_Y|}{D_X + D_Y} \quad (\%)$$
   - 当 $D_X + D_Y > 0$ 时计算，保留高精度定点小数；
   - 默认参考合格限值：$\le 8.0\%$（依据宏亮电缆技术方案）。

2. **毫米绝对差值（原始辅助量，存入 `raw_payload` 供追溯核查）**：
   $$\Delta D = |D_X - D_Y| \quad (\text{mm})$$
   - 对应原件 R5 的 `OvAL` 读数，不丢失毫米原貌。

3. **双轴外径（辅助物理量）**：
   - 记录 $D_X$ (mm) 与 $D_Y$ (mm)，存入 `raw_payload`。

## 四、 现场脉冲计米与换盘信号接入契约

1. **计米器脉冲输入（DI 接口 / 编码器计数卡）**：
   - 光电编码器每转输出 1000 脉冲，线轮周长 0.500 m，换算系数：`1 脉冲 = 0.0005 m`；
   - 边缘端硬件中断累加脉冲，精确计算当前米数位置 `position_m`。
2. **切盘/换盘信号（光电开关 / PLC 换盘信号）**：
   - 收到换盘信号上升沿时，边缘端自动冻结上一盘最后米数；
   - 发送任务结束请求（`/tasks/{id}:end`），清零脉冲计数器，等待下一盘任务绑定。
3. **断光/空料判定防护**：
   - 若 $D_X < 1.0\text{mm}$ 或 $D_Y < 1.0\text{mm}$，或状态字提示“无物体/光路全遮挡”，标记为 `data_status = 'MISSING'`，不作为 `0.00%` 合格测点上报。
