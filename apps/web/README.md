# 慧眼智检 · Web

本目录是「慧眼智检」现有 React 前端，2026-10-21 从根目录 `web/` 原样迁入 `apps/web/`。继续沿用当前页面布局、细节和配色；B2默认连接真实B1后端。历史对照原型位于项目根的 `慧眼智检-原生原型/`（相对本目录为 `../../慧眼智检-原生原型/`）；不读取其本地存储。

管理后台预留在相邻的 `../admin-web/`，当前账号、审计和设置页面仍留在本应用，未删入口。目录及预留规则见 [工程布局](../../docs/13_工程目录与预留服务布局.md)。

## 启动

在本目录执行：

```powershell
npm ci
npm run dev
```

浏览器打开 [http://127.0.0.1:4180/](http://127.0.0.1:4180/)。开发服务只监听 `127.0.0.1:4180`。

构建后用同一地址预览：

```powershell
npm run build
npm run preview
```

## 对照原型

原型目录是 `慧眼智检-原生原型/`。在该目录执行 `node server.cjs`，打开 [http://127.0.0.1:4174/](http://127.0.0.1:4174/)。

当前入口使用服务端HttpOnly会话与PostgreSQL业务数据；账号/密码取项目根`runtime/b1/access.json`，不再接受任意演示密码。只“记住账号”保存显示账号，不保存密码。开发/预览均将`/api`代理到本机4192，因此需先启动B1后端。

原型localStorage和旧页面源码仍供显式注入store的回归测试；默认App不会读取旧演示业务。`localhost`与`127.0.0.1`的Cookie作用域不同，联调统一使用后者。

B2范围：任务/线缆创建、执行、三检测页、历史；其他服务未接入时显示未开通。[验收记录](../../docs/workpackages/B2_前端与B1多盘任务联调.md)。
