# SC01 扫码与秒级传输契约

版本 SC01.v1，2026-11-02。状态：模拟链路自测通过，待用户验收。

## 1 身份与开始采集

- 4196 `#scanner` 独立于送料选择器；文本扫码以回车提交，Code128 PNG/JPEG 识别后立即发送。
- `POST /api/scanner/scan {barcode}`：现有模拟器登录、Origin、CSRF 校验；凭据仅在服务端。
- 服务端复用任务条码解析和设备 assignment，检查授权设备、任务、绑定、版本；再调用受鉴权的边缘 `POST /edge/v1/scan`。
- 边缘先由操作者点击开始采集进入 WAITING_SCAN；正确条码直接进入 RUNNING，无二次确认。同一运行同码幂等，另一任务不得抢占；过期或已结束任务拒绝。
- `GET /api/scanner/state` 转发受鉴权的 `/edge/v1/scanner-state`，显示真实状态、本地保存数、时序待写数、中心待确认数和永久拒绝数。断开显示错误，不生成假数据。
- 本轮只接 OVALITY 与该记录附带的护套配对。扫码不等于送料：线缆预设、设备与送料仍独立；点击“去模拟送料”按服务端盘 ID、任务 ID、设备 ID 填入。

## 2 采集与传输

1. 模拟器每个采样点先保存 SQLite；沿用唯一来源键、采样时间和序号。
2. 边缘核对绑定、Modbus CRC/状态、双轴数据及时间配对；原始样本、转发原文与待传标记在 bbolt 同一事务持久化。
3. 本地 InfluxDB 确认写入后推进投影游标。没有本地时序确认的样本不能进入中心上传批次。
4. 边缘工作循环每秒调度一批，最多500条且约900KB。模拟器→边缘约800KB分批；余量仍留队列，不降采样、不取均值。
5. 中心先写 OVALITY 时序原文/值，再写 PG 身份索引和规则判定；鉴权、格式、身份与绑定预检仍在写入前执行。中心未确认不得给模拟器返回 STORED。
6. 边缘最多等待2秒取得调度器回执，未完成返回503/Retry-After并保留原键。模拟器继续采样，传输独立重试；逐条核对回执身份、数量和状态。
7. 成功/重复/隔离及永久拒绝回执持久化；只移除已确认待传标记，原文保留。重试同键不同内容拒绝，不覆盖。

一秒是调度周期，不承诺故障/超负荷时一秒到达。队列、磁盘达到既有保护阈值时停止新增采集并保留已有记录；不能将有限存储描述为无限不丢数据保障。格式/CRC拒绝的批次保留在来源队列，需纠正输入后处理。

## 3 护套辅助结果

- 原文增加 `raw.data.edge_sheath`；小数采用字符串，保留 A/B 值、样本号、时间、计米补偿、间距配置版本及方法。
- 沿用已有 `sheath-a-mean-minus-b-mean.meter-time.v3`：A 均径减 B 均径，不另除二，不增加产品合格阈值。
- 中心从时序读取原文后，以 Decimal 重算 A/B 均值与差值，核对采样时间差、计米器延迟、配置版本、上游方向及残差。
- 查询返回 `sheath_result`：`VERIFIED / INVALID / UNAVAILABLE / NOT_PROVIDED`，包含 value、unit、reason、pair、method、validation_version。
- 零值/负值保留；无输入或配对失败返回空值和原因。VERIFIED仅表示计算及配对核对通过，不代表护套质量合格。历史记录不回填猜测值。
- 当前复核针对 SIMULATED 的 A/B 原文；真机接入与生产判定另行验收。

## 4 存储及兼容

- 无 PG 表结构迁移；OVALITY 原文/值仍在中心 InfluxDB，业务/判定/去重在 PG；另两指标保持原路径。
- 既有 `/measurements` 列表及详情权限、工厂隔离不变，仅添加派生只读字段。
- 边缘旧记录无回执时通过中心原键去重重新取得回执。配置和数据卷保留；重启后当前采集需重新开始，待传记录继续恢复。
- 工单→检测任务→进入检测/回看检测，以及原始记录详情，可查看护套核对结果。尚未扩展正式报告中的护套质量结论。

## SC01R1 送料入口修订（2026-11-02）
送料页移除条码生成/上传及上传状态门槛。POST /api/passes 不再要求barcode，兼容旧字段但不使用；OVALITY送料只GET边缘scanner-state，核对RUNNING、taskId、bindingId、deviceId，冻结已有间距版本，不执行scan。扫码仍只在独立扫码枪页面或边缘扫码输入完成。缺预设、设备占用、错任务/绑定仍拒绝。
