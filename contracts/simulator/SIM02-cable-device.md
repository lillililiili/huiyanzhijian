# SIM02 线缆与设备模拟契约

2026-10-26｜已实现、自测并部署，待用户验收｜仅开发测试，不代表真机能力。

## 1 独立模型

线缆模型：`name/material_ref/length_m/baseline/defects`。baseline包含铜带宽度、搭盖宽度、铜丝间隙、X/Y直径，单位mm；长度和位置为m。每个缺陷包含`name/metric/start_m/length_m/value_mm`，依次表示问题描述、检测项、起点、长度、异常物理量。搭盖缺陷改变搭盖宽度，间隙缺陷改变间隙，不圆度缺陷改变Y直径。最多20段；区间左闭右开；禁止越界、非正长度、同项重叠，不同项允许重叠。位置最多6位小数，仅为模拟数据精度。

设备模型：`name/device_id/metric/step_m/speed_m_min/lower/upper`。绑定已配置的SIMULATED设备，检测项必须匹配。至少设置一个测试界限，空值表示不设置；等于界限不判异常。设备只读取采样点的局部几何量，不能读取缺陷名称、区段清单或期望判定。

| 检测项 | 当前模拟算法 | 输出 |
|---|---|---|
| SHIELD_OVERLAP_RATE | 搭盖宽度÷铜带宽度×100 | % |
| WIRE_GAP | 局部间隙 | mm |
| OVALITY | 200×abs(X−Y)÷(X+Y) | %，仅现有1.0兼容测试公式 |

不圆度同时保留原始X/Y及差值mm。参考资料中的mm口径、不同设备公式尚未完成适配，不能将当前百分比解释为已确认生产标准。

## 2 本地API与持久化

使用模拟器现有登录、Cookie、Origin和CSRF校验；没有新增平台账号体系。

| 接口 | 功能 |
|---|---|
| GET /api/models/cables、/api/models/detectors | 最近100个模型的最新版本 |
| POST /api/models/cables、/api/models/detectors | `{id,version,data,reason}`；version为期望旧版本，0表示新建 |
| POST /api/passes | `{request_id,cable_id,cable_version,detector_id,detector_version,mode,task_id,spool_id}` |
| GET /api/passes/{run_id} | 冻结模型、预设与实际检出对比、出料结果 |
| POST /api/passes/{run_id}/finish | 重试自动出料 |

模型保存在模拟器SQLite的`model_revision`，按版本追加；过料快照与事件回执保存在`model_pass`。不新增PostgreSQL表。相同期望版本、内容与原因的重复保存返回原结果；不同内容的过期版本返回412。非法模型400、未登录401、权限/CSRF失败403、设备占用或自动发现未配置409；上游失败保留真实原因，不生成成功回执。

## 3 过料链路

BOUND：人员在业务平台准备并开始任务，模拟器取得有效绑定后采样；任务结束由平台操作。

AUTO：平台事先配置并启用自动发现，设备发送ENTER→取得平台任务绑定→检测/上传→全部生成且待传清空后EXIT，报告线缆长度。可指定同盘ID供跨设备任务归属；不依据同名或时间接近自行合盘。模拟器只调用设备HTTP接口，不直接写业务库、不调用人员建单接口。

每次过料冻结线缆和设备版本。采样位置为0、step、2×step……严格小于线缆长度；条数为ceil(length/step)，最多100000条。模拟速度上限600m/min，间隔round(step/speed×60000)须在50～60000ms内。这是定时数值模拟，不是机械实时精度或产线性能承诺。

上传内容包含测量值、位置、设备源判定、观测几何量、模型/算法版本和TEST_ONLY界限；完整预设问题和期望答案只留本地。平台继续独立判定，没有正式规则时可为NOT_EVALUATED，不能用设备PASS代替正式放行。

## ALR02 任务规则方法ID映射（2026-10-27）

线缆模拟器为已绑定任务生成测量值时，method_id使用该任务assignment.rule_snapshot.method_id，使M04/M03按任务创建时冻结的方法和比较规则判定。未绑定或规则未批准时仅使用模拟器专用回退标识，平台应保持NOT_EVALUATED；不得通过模拟器标识绕过方法校验。已验证三项SIMULATED/TEST_ONLY链路；不修改设备1.0字段结构、M03规则或生产标准。记录见ALR02工作包及验收记录。

暂停停止生成，补传可继续；停止保留队列；继续使用原快照、原序号与原位置；重放保留原键原文。自动出料失败保留错误，可重试同一事件；中断或待传未清空时不自动结束。重启需重新登录，不自动开始采样。Windows强停子进程后，现有生产者租约可能最多等待30秒。

## 4 对比与验收

对比按预设区段统计实际采样点及异常点；其他检测项标明本设备不检测；无采样点的短缺陷可以漏检。未预设区段的设备异常单列；不把点检出率等同长度覆盖率。

验收已通过：三项独立检测、半开边界、短缺陷漏采、版本冲突/冻结、权限/CSRF、真实HTTP与PostgreSQL回读、去重、自动进出料、暂停/停止/恢复、重启保留及旧接口诊断兼容。浏览器创建4m线缆，2～3m搭盖不足，0.5m采样，8点中2点异常，平台任务结束并记录4m。

剩余：图像/AI检测、测量噪声与校准、全周测量、完整位置1.1复位/倒退/工序映射、真机适配、正式规则与报告。均不计为本包完成。

## SIM07 线缆参数编辑与预设默认值（2026-10-27）

线缆新建/编辑页面直接编辑baseline五项，默认：tape_width_mm=20、overlap_width_mm=2.5、wire_gap_mm=1.25、diameter_x_mm=40、diameter_y_mm=40，单位mm。缺陷区段之外按baseline取值；区段内只将对应量替换成value_mm，区间规则及验证不变。

新缺陷从0m起、长度1m，随检测项默认：搭盖不足1mm、间隙偏大4mm、不圆度异常段Y向直径48mm；选择检测项后物理值重置为该项默认值，名称只在仍为系统默认名称时切换，用户自定义的问题描述保留。上述值只是便于构造正常/异常模拟；异常是否触发仍由独立设备模型TEST_ONLY范围决定。

当前UI提供换算帮助：搭盖率=搭盖宽度÷铜带宽度×100%，间隙直接按mm，不圆度兼容公式=200×|X−Y|÷(X+Y)%。说明会标示这是模拟值参考，不是产品验收结论。字段仍保存到SQLite model_revision新版本；model_pass冻结内容和过去结果不回写；POST /api/models/cables及其Schema无变化。
