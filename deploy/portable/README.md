# Windows 免安装交付包

任务：G-PORTABLE-20261020，A 类交付基础包。基线 `ae5fe0b`，分支 `docs/project-definition`，目录 `E:\huiyanzhijian`。用户已指定 Windows 10/11 64 位，要求解压后双击启动，不依赖另一台电脑预装开发环境。

## 方案与范围

随包携带经官方 SHA-256 核对的 Node.js Windows x64 运行时、现有 React 前端生产资源、仅依赖 Node 标准库的静态服务及启动/停止脚本。与要求目标机另装 Node 或 Docker 的方案相比，此方案解压即可离线运行；打包后约几十MB。用户电脑只需 Windows 自带的现代浏览器。

允许修改 `deploy/portable/`、根目录说明、交付验证记录和台账；生成包位于忽略的 `release/` 及用户桌面。业务页面、演示规则、数据存储和正式模块接口不变，数据库变更为无。该交付仅提供 M10 演示页面的运行入口，不代表正式 G00、API、HW 或 MES 验收。

## 使用与运行约定

- 双击 `启动平台.bat`：检查完整性所需文件，启动隐藏的本地静态服务，服务就绪后打开默认浏览器。
- 重复点击：校验当前目录实例，复用已运行服务并再次打开页面。
- 双击 `停止平台.bat`：只请求本目录实例停止，不按进程名杀死其他 Node 服务。
- 默认地址 `http://127.0.0.1:4188/`；绑定回环地址，不要求管理员权限或修改防火墙。
- 端口被其他应用占用时显示明确原因，保留原应用；可编辑包内 `平台配置.json` 的 `port`。固定地址有助于保持浏览器本地数据，变更端口将使用另一份浏览器存储。
- 运行状态与日志位于包内 `data/`、`logs/`，需要解压到用户有写入权限的位置。先停止服务再移动或更换目录。
- 本地模拟数据存储在浏览器，同浏览器、同地址刷新/重启可查；本包不包含当前开发电脑浏览器的数据。
- 停止接口使用每次启动随机生成的令牌；静态服务只公开 `site/`，不公开脚本、运行时、状态文件和日志。

## 制作

开发电脑需现有项目依赖和 PowerShell。以下命令构建前端、校验运行时、生成目录和ZIP，目标电脑无需这些工具：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\deploy\portable\build.ps1
```

默认复用本机 Node，要求版本为 v24.16.0、Windows x64，且二进制摘要与 Node 官方发布清单一致。官方运行时和第三方许可证随包提供。脚本不覆盖既有交付目录；指定新输出目录重新生成。

开发验证：

```powershell
node --test deploy/portable/portable.test.cjs
```

交付门禁按 L4 执行：已有前端测试与生产构建、启动/重复启动/停止、端口冲突、静态文件隔离、最终ZIP解压后的最小PATH启动、中文和空格路径、浏览器实际登录及回读。第二台电脑本身未在本机测试中被替代，另记现场结果。
