# 项目总说明

版本：V0.3，2026-10-10。已按原型 `cbd8c76` 审查修订；已确认范围、原型事实、正式建议和待决事项分别标明。本文不证明生产软件或设备能力已交付。

## 项目目标与已确认边界

项目名称为“慧眼智检线缆质量管控平台”。面向 35–220kV 高压电缆生产，贯通检测任务、设备数据、报警处置、盘号追溯、过程质量报告和 MES 输出。

| 对象 | 已确认分工 | 本方开发职责 |
|---|---|---|
| 产品1 金属屏蔽搭盖率检测 | 浪潮 ODM 整机及配套软件、算法 | 接入实际开放数据、关联任务与盘号、平台展示与追溯 |
| 产品2 铜丝屏蔽相邻铜丝间隙检测 | 浪潮 ODM 整机及配套软件、算法 | 确认统计口径、协议适配、业务关联与平台集成 |
| 产品3 电缆不圆度检测 | 上海共久供测径硬件 | 现场采集、有效性、批准方法下的计算判定、报警、本地存储与上传 |
| 统一平台与 MES | 本方开发 | 统一管理、接收、查询、报告及约定的 MES 出站接口 |

三类设备不代表每个工厂只有三台。任务按实际适用工序关联检测项目，不要求每个任务同时包含三项。外径属于不圆度的原始或辅助数据，不另立第四项检测。

项目业务背景包括客户质量管理与投标资料需求；不据此承诺设备配置自动获得加分或符合未核实条款。

## 范围校正

原始资料保存在 `项目资料/`，仅作历史输入，保持原文。原 V1.0 的“35kV及以上”按后续确认收敛为 35–220kV；本期检测内容限定三项。

- D/E 绝缘偏心度、护套厚度比例，以及新增传感器、视觉算法、其他检测指标的菜单与交付，均不自动纳入本期。
- 原台账 P07 为通用导入与人工录入：保留本期三项检测的模板、校验、审核、更正设计；其中 D/E 示例与原台账验收 T12、T13 的扩展指标要求不纳入本期。不能因排除 D/E 而删除整个 P07。
- 旧台账中的任务编号用于历史追踪，新模块编号采用 M00–M10，两者不是一一对应关系。
- MES 首期为约定检测数据输出；工单下发、配方双向同步、自动停机、PLC 生产控制均不默认包含。
- 当前任务为结合已存在原型修订开发文档；不执行历史任务书中的编码、安装、部署、发消息或现场控制任务。

## 建议架构

建议采用“平台模块化单体＋独立设备端＋供应商适配器＋MES 出站适配”。平台通过模块公开接口协作，设备端可离线检测和持久化；先不引入微服务集群。

业务模块内按入口层、应用层、领域层、基础设施层组织。可使用 Controller / ApplicationService / Repository / Entity / DTO 的对应角色，但最终包名随技术栈确定。领域层不依赖 Web 框架、ORM 或外部供应商 SDK。

需立即返回结果的模块交互使用明确公开接口；已提交业务事实引起的异步动作使用可靠事件。不要为了“解耦”把所有普通查询都改为异步消息。

完整模块边界与允许依赖以 [架构文档](03_整体架构&模块拆分文档.md) 为准。

## 第一阶段结果与开工条件

首轮建议先以一类设备实现“任务绑定→采集→存储→展示→异常→查询”。模拟闭环、真机闭环分开验收；选择哪类设备，以协议和实机条件为依据。

27 页全部建立开发映射，但不据页面数量承诺同一迭代全部交付。基础闭环优先；质量分析、模板自定义、暂停恢复、每盘汇总等按决策 T09/T10 和工作包逐项确认。原型菜单中的 HTTP/MQTT/OPC UA 是演示选项，不是已经支持的设备协议。原型阈值 10% / 3mm / 8%、四处间隙平均、不圆度示意、四个电压选项均不替代客户批准口径和设备能力。

业务编码前至少具备：批准的技术栈、目标页面工作包及必要模块设计、公开接口和数据归属、明确允许修改路径、可执行验收场景。缺少测量规则时可开发不依赖该规则的工作，不输出正式质量判定。

审批与缺口统一记录在 [风险与约束](06_风险&约束.md)，模块实施状态记录在 [模块状态台账](modules/模块状态台账.md)。逐页派工与当前可测状态以 [第12份台账](12_页面开发与测试台账.md) 为准，不等整个模块开发完才测试页面。
