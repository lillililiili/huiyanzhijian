# 原型页面与开发映射

版本 V0.3，2026-10-10。代码依据 `cbd8c76`；P01–P27 是本文件沿用原型 README 顺序建立的文档编号，不是已实现的后端模块。正式业务所有权仍为 M00–M10。当前只有原型代码；以下正式接口/规则为建议，审批状态见第06份文档。

本文解释页面内容与业务归属；按页派工及当前UI/API/HW可测状态以 [第12份台账](12_页面开发与测试台账.md) 为准。第10份V1.1和第11份R01规定首轮分期；本表完整原型内容不代表首轮全部承诺。

## 1. 页面基本信息

产品：慧眼智检线缆质量管控平台，35–220kV，三项检测。平台承接已核实设备测量和任务身份，用于质量追溯与处置，输出受控过程报告和客户MES数据。正式职责角色见第08份 BR11；原型只有admin/quality/viewer三档，本地权限不能视为真实鉴权。

## 2. 上下游与生命周期

```text
P09规格 + P21设备 + P19批准规则 → P07建任务 → P08执行/结束
M08/M09真实采样 → M04规范接收 → P04/P05/P06 + P10原始记录
P12补录 → M04待审核 → 审核生效 → 同一测量/异常/报告链
超限/设备故障 → P13列表 → P14处理/复核 → P08质量条件
P11盘号追溯 + P15统计 → P16生成 → P17冻结版本 → 经批准发布
M04/M05/M06有效事件 → P24同步与对账 → 客户MES
P25权限约束全部动作；P26记录命令；P02/P03聚合上述只读状态
```

进入详情须有已鉴权的对象ID与范围；错误ID显示不存在，不能回退显示另一任务。离开查询只改变导航；保存/开始/处置/审核/生成报告等才有业务副作用。生产开始按钮不默认包含机器启停控制。上游的最后采样、接收成功、当前规则、历史快照分别有自己的生效时间。

## 4. 区块逻辑卡

## 9. 状态机与传播

唯一详细定义见第08份 BR02/BR03/BR07/BR09/BR10：任务、连接、新鲜度、记录有效性、判定、资格、报警生命周期、处置、报告类别/发布、MES投递各用独立状态。不得用一个 `status` 同时表达数值合格、任务完成和MES成功。

原型 `pending` 随对象可能指任务待开始、报警待复核、MES待同步，转换时必须携带对象类型。完整状态传播至少覆盖第6节；列表更新不能只显示Toast，必须回读新资源版本。

## 10. AI能力与人工确认

P04–P06/P14/G.02量测图目前为演示素材，辅助标线来自原型数据，不是AI现场检测证据。正式只接入已核实ODM结果或批准的M09计算；保留原始输入、方法版本和证据可用性。没有证据显示缺失，不自行生成图像补位。其他页面无大模型业务决策功能；P14人工复核与P16正式发布不能被自动建议跳过。详见BR13。

## 11. 权限与数据范围

按第08份 BR11，每个读写/导出/文件访问都校验工厂与设备/产线范围。P25/P26/P27的可见性不是“登录就全部开放”；只读查看数据不默认拥有审计导出或接口凭据查看。设备身份只能上传被绑定设备，不能调用人工审核/管理用户接口。原型quality把操作员与审核员合并、admin名称显示为质量管理员的混用属于差异，不作为正式角色定义。

## 14. 端到端验收

按第08份 AC01–AC25逐条实施；最低闭环必须验证：P07建任务→P08实际绑定→测量接收→检测/G.02同记录→P13/P14处置→P11追溯→P16/P17冻结报告→P24真实业务确认，且P26能追溯写操作。
