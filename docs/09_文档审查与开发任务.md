## 仍需独立处理的原型差异

本轮只改文档。以下来自当前源码，作为后续B类原型修复或A类正式实现的输入，不把它们悄悄写成已经支持。

| 原型差异 | 当前证据/影响 | 后续动作 |
|---|---|---|
| 工作台/任务页“今日”使用全量tasks.length | data.js固定日期使演示不易暴露跨日问题 | 正式按BR06；若原型需跨日演示则另派B修复 |

| 设备卡“查看检测”只传metric；回退选择第一项任务 | pages-management设备页；多同类设备会选错上下文 | 正式必须传device_id/task_id；AC01 |
| 规则是每指标全局当前版本，批准流程缺失 | reviseRecipe按metric停用旧版本 | 正式按工厂/规格/工序/方法版本；AC04/12 |

| 报告已冻结数据和模板，但没有完整格式/渲染版本契约 | downloadCSV导出原始value；图表tooltip和报告部分值用固定精度；未发现显示精度设置改写历史数值 | 正式补格式快照与渲染版本，使重导出可复现；这是设计缺项，不认定原型已篡改历史数据 |
| 导入保存后的来源合并为“人工导入补录”、图像为演示图 | importRecords统一source/image | 正式区分IMPORT/MANUAL与SIMULATED，缺证据不伪造 |

| 时间为固定字符串、时区处理简化 | timeAdd、筛选日期、真实审计时间混用 | 正式存UTC+来源时区/真实操作时间，AC08 |

| 原型规则/导入/报告/审计均本地可改 | localStorage及模拟DOM测试 | 不复用作正式持久化/权限/审计方案 |
