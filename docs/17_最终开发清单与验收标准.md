### 20.5 计算优先的具体边界

| 数据/指标 | 可用计算输入 | 当前结论或待确认 |
|---|---|---|
| 最大/最小/均值、极差 | 同方法/单位/范围的有效原始值，明确样本集合；极差为最大减最小 | R1/R3支持；仅收到设备汇总时应标“设备汇总”，不能宣称平台复算全部原始值 |
| 标准差、分布 | 足够的明细值或可核验统计量 | R3/W01支持需求；样本/总体标准差、分桶、按点/时间/长度加权待确认；只有均值/极值不足以恢复分布 |
| 搭盖率、间隙、不圆度派生量 | 对应原始测量量＋已核实的方法/单位 | 原始字段和定义不全时不可计算；R5指定面板的abs(X−Y) mm不能替代任意整机的%不圆度 |
| 本次过料长度 | 可证明属于同一有效计米段的起止读数及方向/复位信息 | B3差值仅“上报长度/未校准”；实际盘长、有效覆盖、合格长度分别管理，不能互相替代 |
| 点符合阈值比例 | 已采用、可判定记录的PASS与FAIL数量 | 现有设计为PASS/(PASS+FAIL)，不能称整盘合格率；无效/未判定数量另列；正式统计范围待确认 |
| 覆盖率、长度符合率 | 批准应检区间、位置资格、覆盖方法及遍次选择 | 沿DP11和第16份；离散点不能直接插值成完整覆盖；零分母或输入不足显示不可计算 |
| 缺陷数量/密度 | 样本、报警事件、物理缺陷区段的各自身份；密度还需可靠长度分母 | 三种数量分开；连续多帧是一次还是多次缺陷、每百米/千米口径待确认 |
| 盘级结论/跨任务汇总 | 适用项、必要覆盖、复检采用、异常处置及批准判定规则 | 不把三个任务的比例简单平均，也不因任务全部结束就判整盘合格；规则尚待确认 |
| 图片、真实盘身份、物理位置 | 真实证据或已批准的可靠关联来源 | 不能仅靠统计数值还原照片，也不能用时间接近自动证明两台设备检测的是同一盘 |

“计算优先”不等于重写设备视觉算法。保留设备原值/原判定与平台计算结果，差异可追溯；平台派生量引用输入、方法、范围和版本。筛选是查询条件，误报复核是质量处置，数据有效性更正是受控流程，三者不能混成“过滤掉不合格数据”。
