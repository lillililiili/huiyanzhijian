## 字段和规则草案

| 字段 | 约束与存储 | 页面行为 |
|---|---|---|
| factory_id | 来自授权范围；引用M01工厂 | 有多工厂权限才可选择；后端再次校验 |
| code、name、cable_model | 必填，长度64/128/128；同工厂code唯一 | 重复时保留输入并提示；是否忽略大小写待目录规则确认 |
| voltage_kv | DEC(10,3)，35—220范围；从批准等级目录选择 | 不将原型四个电压值默认为最终目录 |
| conductor_area_mm2 | DEC(16,4)，大于0 | 单位mm²；JSON十进制字符串，不补空值为0 |
| core_count | 正整数 | 无效数值拒绝 |
| shield_structure | S(24)，按批准目录 | 不擅自删除复合结构；可用明确标测试的TAPE/WIRE样例演练 |
| customer_code、product_type、description | 可选，长度128/128/受控文本上限 | 空字符串规范按Schema确定；不承担客户主数据管理 |
| applicability | 工序与三项metric_code的组合，同规格/工序/指标唯一 | 校验同工厂、适用关系；不读取M03表；不能跨工厂关联 |
| status、version | ACTIVE/DISABLED；乐观锁版本 | 启停不删除；编辑使用ETag和If-Match |

写表归M01：product_specification、specification_applicability，以及按本页幂等约定建立的catalog_command_receipt（采用第04份owner_command_receipt模板）。工厂、工序夹具由M01生成，人员权限和审计调用M00公开接口。本页不创建任务表或配方表。正式迁移需明确非空、唯一索引、同模块外键和枚举约束；当前仅逻辑设计。

## 接口草案与操作

统一前缀/api/v1；完整Schema由本页设计定稿，以下不是已存在的接口。成功/错误封装沿用第05份；权限码建议catalog.spec.read/write，由M00登记。

| 操作 | 候选接口 | 关键约定 |
|---|---|---|
| 列表 | GET /product-specifications | keyword/status/page/page_size及批准筛选字段；返回items/total/page/page_size/as_of；服务端限制工厂范围 |
| 详情 | GET /product-specifications/{id} | 返回规格、适用关系、version和ETag；不存在或不可见按全局策略404 |
| 新增 | POST /product-specifications | 201返回id/version；带Idempotency-Key，同键同内容重试返回同对象；业务编码重复409 |
| 编辑 | PATCH /product-specifications/{id} | If-Match必填；412版本不匹配，428缺版本；事务更新主表及适用关系，保留原输入供刷新比较 |
| 启停 | PATCH /product-specifications/{id} | status变化同样校验版本；不删除历史引用；每次变化写真实操作者审计 |

目录规则与文本上限、默认排序/页长、重复编码错误码、状态/结构允许变化条件必须在本页C设计补成可校验Schema后再A编码。不虚构“规格已被引用可以随意改结构”；影响历史的字段使用任务既有快照，关键类型变更限制待评审。

## 可直接执行的验收用例

以下为预期用例，实际结果全部未执行。真实目录未确认时只验测试夹具对应流程，不能声称生产档案规则验收通过。

| 编号 | 操作 | API模式预期结果 |
|---|---|---|
| P09-01 | 可写用户新增有效规格，保存后刷新，再重启API查询 | 同一id、字段和适用关系仍存在；数据库持久化，非浏览器本地缓存 |
| P09-02 | 分别提交空必填、面积0/负数、芯数小数、范围外电压 | 前后端均拒绝并指向字段；没有半条规格或孤立适用关系 |
| P09-03 | 同工厂提交重复编码，再重发同一幂等请求 | 编码冲突409；同幂等键同内容只生成一个id；不同内容冲突 |
| P09-04 | 输入条件筛选并翻页、清空筛选 | total与过滤结果一致；不漏页/重复页；空结果有明确提示 |
| P09-05 | 两窗口读同一版本后分别编辑 | 先提交成功，后提交412；不覆盖先提交值；保留冲突窗口输入供用户处理 |
| P09-06 | 只读用户尝试直接POST/PATCH；篡改范围提交另一工厂工序 | 后端403或约定的不可见404/关联拒绝；仅隐藏按钮不算通过 |
| P09-07 | 禁用规格，刷新查详情；检查可选档案公开查询 | 状态与版本正确；启用候选集合不含禁用对象；历史不被删除 |
| P09-08 | 加载时断开API、保存返回503，然后恢复重试 | 明确失败与重试；无假成功和本地回退；幂等避免重复；真实操作者和request_id可追踪 |
| P09-09 联合 | P07实现后选择该规格创建任务，随后改规格/禁用，再查新旧任务 | 新任务不能选择禁用规格；旧任务保持创建快照；在P07交付时执行，不伪造本页当前通过 |

UI模式可提前验证交互和错误反馈，但不能抵扣上述服务端/持久化结果。API提测须本页范围内P09-01—08可执行；P09-09作为明确延期的跨页验收登记，不因本页通过而自动关闭。
