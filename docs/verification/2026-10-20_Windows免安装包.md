## 适用范围

本包是当前 React 演示平台的离线交付，无正式后端、真机接入、真实 MES 或生产级账号服务。浏览器本地数据仅在相同浏览器和地址下保留，不随 ZIP 自动搬迁；无痕窗口或清除站点数据会影响保存。目标电脑需现代浏览器和可写的解压目录。第二台电脑尚未现场执行；本机最小 PATH 测试验证的是无需全局开发工具，不等同于干净 Windows 虚拟机测试。正式模块验收与冻结状态不变。
