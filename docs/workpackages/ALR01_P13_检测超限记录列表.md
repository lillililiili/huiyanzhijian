# ALR01｜P13检测超限记录列表

日期：2026-10-27  
类型：A，新页面业务子范围  
页面：P13「报警事件」的只读检测异常列表  
模块：M10展示；只读依赖M04测量查询和M00既有会话/授权  
状态：源码已接入；随CAT02B共享前端构建部署至4181；ALR02已用真实后端记录回读FAIL总数18、当前页18；筛选/分页/详情等其他交互待验收，未冻结。首验时total=0是当时数据库没有FAIL的真实空态。

## 1. 目标与边界

将平台数据库已保存、服务端 `quality_result=FAIL` 的测量记录显示在P13，供用户筛选、分页、核对检测值和查看关联任务。页面按测量记录展示，不把FAIL条数称为正式报警事件数。

本子范围不创建M05报警对象，不实现事件去重/聚合、恢复、确认、处置、复核、责任分派或报警统计；不修改阈值、测量事实、M04/M05后端、数据库、权限表和Docker。现有React页面、蓝白配色和公共UI组件继续使用。数据只来自M04服务端接口，不使用本地静态列表、缓存样例或错误回退数据。

## 2. 页面交付

### 2.1 查询摘要

- 筛选范围总数取服务端分页响应 `total`，口径为当前筛选条件内的FAIL测量记录数。
- 当前页条数、模拟来源条数、真实设备来源条数仅按当前页实际返回项统计并明确标注。
- 显示服务端快照时间；首次查询和第一页可每5秒刷新，用户可暂停。翻到后续页后自动刷新不打断浏览。

### 2.2 筛选与列表

- 检测项目限金属屏蔽搭盖率、铜丝屏蔽间隙、电缆不圆度三项。
- 支持任务、线缆、设备、数据来源及采样时间范围筛选；支持每页25/50/100条和服务端游标翻页。
- 固定按最新接收记录优先；表格显示采样/接收时间、线缆/工单/任务、检测项目/设备、实测值/单位、可用的规则或判定说明、来源米数、资格/接收状态和数据来源。
- 来源米数标明“未验证”，不宣称精准定位。

### 2.3 记录详情与追溯

- 详情展示记录ID、设备、采样/接收时间、判定原因、规则快照（仅从可见关联任务读取）、来源/资格/接收状态、来源米数和原始记录字段。
- FAIL记录复用现有逐条异常实值预览；只有现有实值与任务规则可匹配时才绘图。预览受限或缺资料时明确说明，不生成假图。
- 记录带有关联任务时提供任务详情和该任务FAIL历史入口；无关联任务时明确显示。

### 2.4 状态与错误

- 首次读取显示加载；成功且total为0显示真实空状态；接口失败显示错误，不用“无记录”掩盖。
- 筛选改变后重置游标与页码；过期/不匹配游标按API错误展示并允许重新查询。
- 页面不提供删除、修改判定或人工关闭报警操作。

## 3. 数据与接口

查询复用M04公开 `GET /measurements`：`quality=FAIL`、`order=desc`、`limit=25|50|100`，可选 `metric_code`、`task_id`、`spool_id`、`device_id`、`environment`、`from`、`to` 与签名 `cursor`。服务端返回 `items`、当前筛选 `total`、`has_more`、`next_cursor`、`as_of`。读取依赖M04在PostgreSQL中的测量、判定、资格记录和既有查询权限范围。

本工作包不新增接口或数据库迁移。浏览器不直连PostgreSQL。前端仅展示服务端已判定FAIL的记录，不自行比较阈值产生异常。
