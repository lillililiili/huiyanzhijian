## m00.access_credential

独立设备接入凭据及工厂/设备/来源环境范围。归属M00。

| 字段 | PostgreSQL类型 | 可空 | 默认值/生成 | 业务含义 |
|---|---|---|---|---|
| id | text | 否 | — | 本表稳定主键，具体生成/作用域见约束 |
| token_hash | character(64) | 否 | — | 令牌SHA-256；不保存可使用的明文凭据 |
| factory_id | text | 否 | — | 工厂归属及访问隔离键 |
| device_ids | text[] | 否 | — | 凭据允许访问的设备ID集合 |
| data_environment | text | 否 | — | SIMULATED/REAL，来源凭据限定，不可混算 |
| scopes | text[] | 否 | — | 设备凭据允许调用的接口权限 |
| created_at | timestamp(6) with time zone | 否 | now() | 创建时间，数据库默认UTC时刻 |
| expires_at | timestamp(6) with time zone | 否 | — | 凭据/会话到期时间 |
| revoked_at | timestamp(6) with time zone | 是 | — | 会话/凭据撤销时间 |
| version | bigint | 否 | 1 | 乐观并发或追加事实版本；按表定义 |

约束：

- `access_credential_data_environment_check`：`CHECK ((data_environment = ANY (ARRAY['SIMULATED'::text, 'REAL'::text])))`
- `access_credential_device_ids_check`：`CHECK ((cardinality(device_ids) > 0))`
- `access_credential_pkey`：`PRIMARY KEY (id)`
- `access_credential_token_hash_key`：`UNIQUE (token_hash)`

索引：

- `CREATE UNIQUE INDEX access_credential_pkey ON m00.access_credential USING btree (id)`
- `CREATE UNIQUE INDEX access_credential_token_hash_key ON m00.access_credential USING btree (token_hash)`
