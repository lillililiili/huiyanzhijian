# CAT02：三项检测指标与产品规格双向选择（TEST_ONLY）

日期：2026-10-27

## 目标与范围

修正测试阶段产品规格档案编辑页只按屏蔽结构显示两项指标、指标页不能维护适用规格的问题。P09规格编辑和P18三项指标页均维护同一组M01 `specification_applicability` 关系，三项指标都可选。

仅限当前TEST_ONLY模拟联调。放开跨屏蔽结构选择，不代表产品工艺兼容性或生产质量标准已批准；真实设备/MES、生产规则及第四项指标均不在范围内。

## 实现

- `apps/web/src/live/CatalogPages.tsx`：规格编辑列出设备目录中已有的工序/三项指标组合及档案现存组合，提供全选/清空；测试期不按屏蔽结构隐藏指标。保存仍通过M01既有规格命令。
- `apps/web/src/live/OperationsPages.tsx`：三项指标页为有 `catalog:write` 权限的用户提供“选择产品规格”弹窗。按指标选择，支持全选/清空；显示停用标记及已选计数。选择会给该规格添加当前接入该指标的工序；取消选择仅移除该指标，保留其余指标。
- `apps/web/src/live/LivePages.tsx`：向指标页传递既有API客户端、命令、用户及刷新函数。
- `apps/platform/modules/m01-catalog/management.ts`：不再依据屏蔽结构拒绝三项合法指标的明确适用选择；保留工厂/工序校验、metric_code白名单、去重、至少一项、权限、If-Match、幂等、事务及履历。

## 契约与数据影响

调用既有 `GET /catalog/specifications/{id}` 读取完整记录及适用关系，再通过既有 `POST /catalog/specifications/{id}` 更新；不新增HTTP路由、字段、权限码、表或迁移。每个规格仍单独走原乐观锁版本并新增档案履历；历史任务快照不变。

指标页允许一次改多个规格，但前端逐个提交单规格事务，跨规格不是原子操作。提交前先读全体待改规格并检查每个规格至少保留一项；提交中遇冲突/网络失败时，保留已成功的规格更新，刷新数据并提示用户核对后重试。
