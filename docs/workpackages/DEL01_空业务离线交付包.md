## 4. 发现与修复

1. 初次PG临时socket服务使健康提前通过：改为TCP localhost检查。
2. 新建共享连接卷写入EACCES：initialize一次性root写配置文件，后端只读挂载。
3. 历史迁移含默认MES演示端点：在严格首个空库初始化分支移除。
4. Windows PowerShell默认编码可能无法读取中文路径校验项：校验JSON明确UTF8。
