# DET01 检测记录分页与完整趋势

2026-10-27｜B类Bug修复｜P04–P06检测页、P10历史页｜M04、M10。

## 问题与目标

检测页表格原来固定取最近100条且没有翻页控件；趋势图也只使用该100条，所以任务较早米数的异常不会出现在图上。历史页有游标翻页，但没有展示匹配记录总数、总页数或可选页长。

检测页和历史页均在表格底部提供上一页/下一页、当前页/总页数、筛选后总条数及每页25/50/100条选择，默认每页25条。检测页移除标题区“全部历史”快捷入口。已结束任务的趋势图读取该任务在同一游标快照中的全部记录；检测表格仍按选择的页长分页。趋势点击仍绑定原始测量记录。运行中趋势保留当前刷新窗口。

## 归属与接口

- M04 `GET /measurements` 在现有只读重复读事务中返回当前筛选范围的 `total`；计数受同一入库序号上界、任务/设备/指标、时间、有效性、判定、来源和接收状态过滤条件约束，不包含游标位置。游标继续绑定筛选和排序。
- M10页面沿用现有测量查询、Panel/DataTable与样式，无表结构、迁移、规则或测量事实写入。
- 可修改路径限于 `apps/platform/modules/m04-measurements/api.ts`、`apps/web/src/live/Measurements.tsx`、`apps/web/src/live/LivePages.tsx`、相关类型/测试、M04/M10/B2/P10文档及本工作包验收记录。

## 验收场景

1. 有筛选的记录集跨越多页时，底部显示同一筛选范围的总条数和总页数；上一页/下一页边界正确。
2. 选择25/50/100条会重新从首游标查询；跨页返回后条目顺序和精度不变。
3. 多页已结束任务的米数轴覆盖任务首末位置，较早的异常点也能定位；点击点仍打开对应记录详情。
4. 查询无数据和查询失败时不伪造总数或页数；不改变原始记录、判定、阈值和权限。
