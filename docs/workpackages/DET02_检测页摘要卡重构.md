# DET02 检测页摘要卡重构

2026-10-27｜B类重构｜P04–P06检测页顶部四格｜M10展示，读取M04测量结果。当前源码路径为外层 `apps/web/`；外层应用未纳入内层Git。内层文档基线 `da95600`，分支 `docs/project-definition`。

## 问题与目标

当前四格把任务结束后的通信离线状态、单条最新值、当前表页超限数和本页时间并列。单页统计容易被看成整项任务结果，时间又重复出现在记录表里；零值也没有位置和判定语境。

四格调整为：

1. **任务状态**：突出待开始/检测中/已结束等任务状态和数据来源。只有运行中的任务展示通信与采样观察状态；已结束任务不以“通信离线”作为当前问题。
2. **采样概况**：已结束任务使用检测趋势已完整读取的任务记录汇总总条数、有效/无效/缺测和隔离；运行中明确标为当前页范围。完整数据读取中或失败时不把当前页冒充整项任务统计。
3. **判定概况**：按服务端保存的PASS、FAIL、NOT_EVALUATED计数，分别显示“符合当前规则、超限、未判定”。未判定不等于符合；不计算整盘合格率。存在超限记录时提供现有按真实记录和任务冻结规则生成的图片入口。
4. **重点记录**：存在超限时展示最近一条超限记录的值、时间和来源米数；无超限但有数值时展示最大实测值记录，清楚标注其不是超限结论。点击可查看原始记录。来源米数为空时显示未知，非空时仍注明未验证。

本轮仅改P04–P06前端摘要卡、样式、相应回归和文档；不改M04/M03接口、数据、判定规则、表结构、异常图片匹配逻辑或其他页面。已有实值示意图只继续用于存在明确FAIL的记录，不用它替代现场照片。

## 验收场景

1. 已结束的200条任务完整读取后，四格均按本任务全量统计，不随下方表格翻页改变。
2. 运行中只显示当前页统计并明确标注范围；不把部分数据称为全任务汇总。
3. PASS/FAIL/NOT_EVALUATED数量与记录一致；未判定显示为未判定，不能显示成合格。
4. 有明确FAIL时，重点记录对应真实FAIL行，原始记录抽屉和现有异常实值图片入口均关联本任务记录；无FAIL时不出现异常图片入口，最大值记录标明“非超限结论”。
5. 位置缺失、完整趋势加载中/失败、零条记录和窄屏下文案准确、无空白或溢出。

## DET02R1 运行任务接收总数显示（2026-10-27）

用户反馈运行中的任务卡片显示当前页条数，无法看到任务累计接收总数。采样概况主数字改读 `/measurements` 分页接口返回的 `total`，服务端按任务筛选统计；运行任务沿用现有自动刷新周期。有效、无效、缺测、隔离细分仍按当前页统计并明确标注。结束任务同样显示服务端总数；历史查询显示当前筛选范围总数。接口失败或缺少总数时显示失败/不可用，不回退为当前页长度。

范围：`apps/web/src/live/Measurements.tsx` 及对应既有回归断言；不改M04 API、数据库、规则和UI风格。验收条件：总数40而当前页25时主数字显示40；翻页不将总数变为页大小；运行中刷新后总数随新接收记录更新；错误/缺失总数不显示伪值。

状态：代码已修改；本轮未运行测试/构建、未做浏览器回读、未部署，待验证与用户验收。
