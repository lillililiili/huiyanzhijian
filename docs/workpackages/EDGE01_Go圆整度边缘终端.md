## 设计
- 独立 Go 服务内嵌网页，Chromium app 启动器；真实设备未连接时为空态，无测试业务种子。
- 主判定 min(X,Y)/max(X,Y)，单位1；X/Y必须有效且大于0；用户配置下限，无默认生产阈值。
- 依据 demo 0x0200 六寄存器、状态/平均/X/有符号X偏移/Y/有符号Y偏移，缩放1000可配置。保留原始寄存器、采集时间、公式版本、配置/工单快照。旧规范0x0041及百分比方法不混用。
- Modbus RTU真实串口与Modbus TCP读保持寄存器；只读FC03，不写PLC。
- VictoriaMetrics独立本机时序库保存数值趋势；bbolt事务库保存原始采样、订单、事件、配置、上传游标。时序库投影失败不丢原始记录，持久游标补写。
- 采集、持久化、时序写入、中心补传、UI刷新分离；UI不按采样次数重绘。数据先落本地事务再发布UI。
- 中心接口版本edge.v1，机器令牌认证，按记录ID幂等并要求明确业务ACK；暂不调用现有4192未实现的接口。无中心地址时不影响本地采集。

## 验证
单测：公式、CRC、异常状态/无物体、错误帧、配置、任务生命周期、重复ACK。真实 Modbus TCP协议测试与串口伪终端测试；50/100Hz完整持久化压力测试、重启保留、时序库查询、断网补写。UI真实浏览器启动/暂停/结束/历史/设置/全屏与1280/1920布局。HW真机及中心真实业务联调单列未测。
9600bps不能承诺50Hz RTU：25字节8N1线上传输已约26ms，另有帧间隔及仪器刷新；软件性能与仪器有效刷新频率分别报告。
Ubuntu amd64/arm64静态服务二进制，架构检测；实际目标为Ubuntu26.04 amd64桌面容器。其他内核/架构只记录构建情况，不声称验证。
