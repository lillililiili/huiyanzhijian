# IMG04 原始记录现场画面示例

2026-10-27｜B类页面增量｜P04–P06检测记录详情抽屉｜M10前端展示；不改M04数据契约。

## 目标

在“原始测量记录”抽屉的采样事实下方，按指标显示用户提供的检测示例图：OVALITY显示电缆截面不圆度示意图，SHIELD_OVERLAP_RATE显示金属屏蔽搭盖异常图片。图像仅作指标外观参考，不与当前测量值、米数、判定或质量证据建立绑定。

## 排版与交互

- 仅当所选记录的检测项为OVALITY或SHIELD_OVERLAP_RATE时显示相应图片。
- 不圆度图保留原图内“AI生成演示图·非现场实测”标识；搭盖图标为“用户提供异常示例·非本次记录实拍”。
- 图片保持原比例完整展示，不裁切；移动窄屏按容器宽度缩放。
- 标题、替代文本和说明对应当前指标；示意图片不作为当前记录判定依据。
- 保留现有FAIL实值绘图逻辑、原始字段、JSON和关闭行为。

## 边界

本包只展示用户提供的静态素材，不写测量记录、照片字段、API、数据库、规则或报告。图片不是当前记录的图像证据，不得据此改变判定；真实设备现场拍照和与采样记录绑定仍待图像证据接入专项。

## 验收

1. OVALITY记录只显示不圆度示意图；SHIELD_OVERLAP_RATE记录显示搭盖异常示例图。
2. 图片完整、不变形，窄屏不横向溢出；两项图片区分清楚，标签和说明不混淆。
3. 两图均清楚说明与当前记录非实拍、非质量判定依据；不圆度图另外保留AI示意标识。
4. 其他指标不显示这两张图；当前记录的状态、质量判定和技术JSON保持原样。
