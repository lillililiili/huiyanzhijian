## 3. 已实现的变化

- P20 预览改为样张版式：显著展示“模板样张 / 示例数据”，对象身份、报告编号、规则和时间改为说明性占位，不伪装为实际生产记录；汇总图表示例有明确模拟标签。
- 增加“导出模板样张 PDF”，通过浏览器打印对话框保存为 PDF；打印样张仅包含 A4 报告页，页面外壳和模板属性面板不进入 PDF。
- 增加 donut 判定构成、横向合格率柱和最小/平均/最大值范围图；不使用折线趋势。样例和正式报告均提供文字数值与无数据状态，图表不计算或推断生产限值。
- P20 编辑器仅保留当前快照支持的 Logo、汇总图表和来源声明开关；旧版本记录中的报警/明细/设备布尔字段仍原样保存，只作为历史字段展示，不在新版本编辑或正式输出中冒充已支持数据。
- P17 使用报告自身的冻结统计绘图；缩小指标表宽度，修正单项报告标题；将虚假的 `VERIFIED_IMMUTABLE` 标签改为“已冻结快照”。本地预览种子带非正式样张提示，隐藏发布和防伪证书导出；URL ID 不匹配时不再自动回退到另一条样例报告。
- A4 样式增加分页与表头处理、颜色保留、卡片断页保护及窄屏响应式规则。
