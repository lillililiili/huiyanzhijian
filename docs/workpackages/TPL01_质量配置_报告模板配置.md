## 1 目标页面与需求范围
- **目标端口与入口**：4181 端口平台（业务前端 `apps/web`）→ 质量配置 → 报告模板配置（路由 `#templates`，对应系统架构台账 P20）。
- **背景与解决的问题**：此前访问业务前台 `#templates` 页面时显示为待开发占位提示（“报告模板维护与受控版本待开发”）。本次根据系统总体设计（第03、07、08、12、17份文档）和高压电缆质量检验报告受控标准，为 4181 平台完整开发出工业级、高保真且符合整体逻辑与系统当前风格的报告模板配置页面。

## 2 核心设计与业务逻辑
1. **多分类报告模板支持**：
   - 支持三大电缆质量检验报告场景的模板切换与独立受控配置：
     - **单项指标检测报告模板**（针对金属屏蔽搭盖率、铜丝间隙、电缆不圆度等专项检测）；
     - **整盘多指标综合检测报告模板**（涵盖多工序、整盘汇总与综合判定）；
     - **工单批次质量汇总报表模板**（按工单及生产批次汇总多盘流水）。
2. **高保真 A4 纸质 / PDF 预览（所见即所得）**：
   - 提供标准 A4 报告排版纸质容器（白底、微边框、公文阴影、企业级页眉、双栏元数据表格）；
   - 展示受控报告编号（如 `RP-20261028-001`）、生成时间、受控版本标签、报告大标题与副标题；
   - 动态受控可选区块：
     - 品牌 Logo 标志显隐开关；
     - 全线量测波动与趋势图表（含图表模拟占位）；
     - 超限报警与质检复核处置记录表格；
     - 逐米量测明细数据摘要与“完整明细作为附件导出”说明；
     - 检测设备与工位参数快照；
     - 数据来源环境真实性声明（REAL / SIMULATED 标识）。
3. **签审责任与免责声明（严守合规红线）**：
   - 配置检验员、复核人、质量负责人的签字留白栏；
   - 依据系统合规要求（AC17、DP15.02），明确注明：“签审栏为纸质/PDF打印展示内容；文字签名不冒充具有法律效力的电子签章与生产放行授权。”
4. **受控必备要素（不可隐藏的质量安全红线）**：
   - 界面右侧设置专栏公示五大不可缺省要素：报告编号与时间戳、生产实体事实标识、冻结判定规则快照、阶段/最终报告真实判定、数据来源环境标识；
   - 严格禁止通过模板隐藏异常、缺测或历史判定依据。
5. **受控版本机制与履历管理**：
   - 每次编辑保存时强制要求填写“修改原因”，自动递增受控版本号（如 V1.0 → V1.1）；
   - 提供完整版本履历弹窗，记录每次修订版本号、生效状态、修改人、修改原因与保存时间，并支持点击“查看快照”回看历史配置；
   - 明确遵循系统约束规则：**“新版本模板仅作用于保存后新生成的报告；已有历史报告保持生成时的原始快照，禁止被新模板重绘覆盖。”**
6. **权限控制与防误操作**：
   - 具备 `quality:write`、`rules:write` 或管理员权限的用户允许编辑与恢复出厂；
   - 只读账号（无上述权限）显示“当前账号仅具备只读权限”提示，编辑按钮置灰禁用，杜绝越权；
   - 提供“恢复出厂预设模板”功能，恢复同样生成受控新版本并留存履历。
7. **数据持久化与广播机制**：
   - 存储于客户端受控命名空间持久化层（`huiyan_report_templates_v2` / `huiyan_report_template_versions_v2`），刷新不丢失；
   - 变更时广播 `huiyan-template-changed` 全局自定义事件，为后续报告生成提供统一规范接口。
