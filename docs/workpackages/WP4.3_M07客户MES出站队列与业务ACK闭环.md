## 二、 架构与数据库设计（010 迁移）

在 PostgreSQL 中引入全新 Schema `m07`，建立了客户 MES 出站投递、端点配置与对账表：
1. `m07.mes_endpoint`：存储受控 MES 目标端点、访问凭据（Token 脱敏）与超时策略；
2. `m07.mes_delivery`：出站投递队列持久化表，支持状态机（`PENDING` -> `SENDING` -> `SENT` / `FAILED`），记录业务键、重试次数、客户 MES 业务回执编号 `business_ack`、回执时间与不可变质检完工数据包快照。

---

## 三、 核心业务能力与 API 清单

平台提供如下受控 REST 接口：

| HTTP 方法 | 接口路径 | 功能说明 | 权限控制 |
|---|---|---|---|
| `GET` | `/api/v1/mes/deliveries` | 出站投递队列查询（支持状态、任务 ID 筛选，查看投递与对账结果） | `data:read` |
| `POST` | `/api/v1/mes/enqueue-task` | 任务完工质检包打包出站：自动聚合任务下各项测点均值/极值与合格判定，签名并发送 | `task:write` |
| `POST` | `/api/v1/mes/deliveries/:id:retry` | 手动触发重试失败记录：重试失败投递，获取业务 ACK 并更新状态 | `task:write` |
| `POST` | `/api/v1/mes/mock-receiver` | 本地自闭环模拟接收桩：接收出站报文并返回标准业务 ACK | 公共端点 |
