# M08 浪潮 HTTP 数据来源适配

ODM01，2026-11-02，B类重构。已实现、隔离API/UI自测通过，待部署与用户验收，未冻结。

职责：按两份厂商HTTP分页查询文档读取搭盖率与铜丝间隙，保存供应商原文、显式完成单位/比例与任务身份映射，再经M04公开1.0接口发送。允许依赖M00/M01/M02/M04公开HTTP；不直接读写平台业务表，不修改算法或生产规则。

源码：工程根adapters/inspur/http；模拟器宿主在tools/simulator/src/vendor-http.ts及Queue/DeviceClient装配。独立采集器SQLite仅保存来源行、冻结上下文、出站包和回执。平台M01通过017追加原文版本；M04仍持有业务测量与判定。

正常：显式任务匹配→冻结绑定→查询分页→持久化原文/出站包→M04逐条回执→STORED/QUARANTINED。HTTP或回执失败保留PENDING；同ID异内容拒绝覆盖；任务配置冲突停止。未知单位/缺值不补零，不判合格。PITCH独立于GAP，不扩为新检测指标。

验证：21项接口/出站/隔离定向测试、8项模拟器回归、5组真实PG/API集成及1组独立采集器真实PG重启验证；浏览器实际启动两项各4条，原有自动化各4条，共16条原文逐条一致。HW/MES未验证。

当前页面/P04、P05来源与原文回读可测，布局未变。配置网页、常驻调度、真机参数及现场验收未完成。详见ODM01工作包及工程根临时文件夹/ODM01_浪潮HTTP接口统一/验收记录.md。
