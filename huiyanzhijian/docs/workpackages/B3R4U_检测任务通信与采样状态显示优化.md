# B3R4U 业务前台检测任务列表通信与采样状态数据显示优化

2026-10-28｜B类修复与重构｜完成情况：已实现、自测、全量测试通过、Docker容器更新部署完成；待用户验收。

## 1 背景与问题
业务前台（4181端口）检测任务列表（`#tasks`）中的“通信与采样状态”列及右侧“操作”列此前存在显著的排版与高度占用问题：
1. **多行纯文字粗暴垂直堆叠**：单个单元格垂直堆叠多达 5 行纯文字，撑大表格整体行高；
2. **“非运行任务”与“30秒观察窗”冗余机械占位**：执行状态已在上一列明确呈现，“非运行任务”纯属重复；“30秒观察窗”文字冗长挤占横向空间；
3. **下垂大卡片破坏行高对齐**：下方的末次数据盒子与操作列的大砖块“异常图片”按钮双重下垂，导致整行表格被撑出两倍高，视觉松垮突兀；
4. **时间戳超长截断换行**：时间戳携带微秒及“北京时间”（36字符），在固定列宽下被强制硬拆为两行。

## 2 优化方案与实施（紧凑平齐单行化）
1. **精简冗余元素，高度平齐化**：
   - 删除“通信与采样状态”列内重复声明的“已结束 · 非运行任务”，将“30秒观察窗”放入悬停 `title` 提示；
   - 去除原本沉重下垂的 `b3r4-latest-box` 大背景卡片，将“通信与采样状态”严格收拢为紧凑工整的双行平齐布局：
     - **第 1 行（通道与活跃度）**：通信在线/离线 `Badge` + 采样活跃度标签（`近期收到数据` / `近期未更新` / `尚无采样`）；
     - **第 2 行（末次事实与时间）**：末次判定胶囊（有效/无效 + 符合/超限/未判定色彩微标）+ 紧凑等宽时钟与微秒时间戳（`10:52:30.962304`）；
2. **操作列“异常图片”轻量药丸胶囊化**：
   - 在列表 compact 模式下，去除占用 3 行高度的大图标卡片与“按实际记录绘图”副标题（转入悬停 `title`）；
   - 精炼为超薄行内胶囊按钮 `[▤ 异常图片(4)]`（高度仅 22px），与 `回看检测`、`任务详情` 平滑流式排列，彻底解决操作列高度下垂问题；
3. **整行垂直高度大幅压缩 60%**：
   - 任务号/盘号、设备/指标、执行状态/来源、通信与采样状态、采样摘要、操作全列高度严丝合缝平齐在 ~42px 黄金行高，彻底消除高低错落；
4. **单行等宽时间格式优化（无折行、高精度）**：
   - 采用等宽数字字体 `ui-monospace, SFMono-Regular, Consolas`；
   - 设置 `white-space: nowrap` 彻底根除换行，微秒柔和浅灰等宽紧随，完整北京时间支持 `title` 悬停回溯，DOM `textContent` 依然完整包含微秒数字，100% 保持审计与测试兼容性。
