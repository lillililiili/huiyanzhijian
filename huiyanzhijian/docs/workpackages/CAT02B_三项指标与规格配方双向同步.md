## 目标与范围

在测试范围内，让规格档案可以选择全部三项检测指标；配方编辑器可以选择全部启用产品规格，并将配方选择同步到指标适用关系。仅处理 P09 规格档案、P18 指标关系展示及 P19 配方编辑的前端行为，保持现有 React/TypeScript 技术栈。

三项指标仍为金属屏蔽搭盖率、铜丝屏蔽相邻铜丝间隙、电缆不圆度。此变更用于模拟联调，不批准任何生产阈值或规格适用规则。

## 实现与数据关系

- P09 显示三项实际工序/指标选择，增加“全选检测项”和“清空选择”，并以紧凑布局同时展示全部三项。
- P19 展示全部启用产品规格，可选择全部启用规格或指定规格；未关联当前指标的规格会标明“保存时同步到规格档案”。
- 保存配方前通过现有 M01 规格资料 API 补齐所选规格的指标适用关系，再调用现有 M03 配方 API。P18 与 P09 在重新读取后显示同步结果。
- 配方版本的适用规格仍写入版本快照。既有配方版本不被改写；从一个配方移除规格不会删除产品档案上的通用指标关系。
- 不改 API 契约、数据库结构、规则阈值、测量公式或后端服务。跨 M01/M03 保存不是单一事务；若后续配方写入失败，页面提示规格关系已同步，用户可重试配方保存。

## 用户验收路径

1. 打开 `http://127.0.0.1:4181` 并登录。
2. 进入“产品规格档案”，编辑一条测试规格，检查三项检测指标是否同时可见；可点“全选检测项”，保存后在规格详情及“三项检测指标”页确认三项关系。
3. 进入“配方与判定规则”，选一项指标并新建测试配方。选择“全部启用规格”或指定之前未关联该指标的规格，按页面要求填写测试依据并保存为新版本。
4. 回到 P18/P09 检查适用关系；再编辑该指标配方，验证相同规格显示已关联且可继续选择。
5. 使用测试数据完成验收，不把测试阈值当作生产批准规则。
