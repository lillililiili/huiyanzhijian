- 从R6《浪潮星耀线缆智能产品手册20260422.pdf》PDF第10页直接提取凹坑、卷边、闪缝三张原图；保留原红框与文字，不生成AI图片。
- 该页属于铠装ISA-GD-4120/5120。按用户指定用于交互初验，**不作为当前三项检测的实际图像、缺陷分类或设备能力证明**。
- 任务数值和超限状态来自现有API/PostgreSQL；图片为随前端发布的固定手册示例，不写入任务证据、测量原文、CSV或质量结论。
- 缩略图、预览弹窗持续标注“手册示例 / 非本次实拍”，显示原页和产品类型；不自动将超限映射成凹坑等类型。

## 3 验收标准

| 场景 | 通过条件 | 完成情况 |
|---|---|---|
| 异常任务 | 真实摘要failed>0显示预览入口；任务详情显示3图；任务编号正确 | 自测通过 |
| 无异常/无采样 | 不生成缺陷图片或伪异常；无采样与暂无超限分别说明 | 自测通过 |
| 图片查看 | 可点击放大、切换3图、关闭/Escape退出、焦点返回；窄屏可用 | 自测通过 |
| 实时与历史 | 当前窗口FAIL可查看；历史FAIL详情可查看；正常记录不展示 | 自测通过 |
| 失败状态 | API失败不回退示例任务；图片失败显示明确提示和重试 | 自测通过 |
| 数据与部署 | 只读既有API，既有数据不改；仅更新web4181，其他容器不重建 | 自测通过 |
