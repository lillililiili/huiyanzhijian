## 实现约定
- M08提供共用分页HTTP客户端和字段映射；设备/模拟设备查询结果经过同一个适配器后调用M04公开接收，不直接写业务表。
- 模拟器新搭盖/间隙采样先持久化供应商字段，再经HTTP查询回读与映射；原队列历史保留旧格式补传，不静默改写。
- 模拟约定：POST；搭盖路径按原件，间隙使用原件建议路径；buildPercent按百分数、buildWidth按mm、日期为UTC+08:00。全部标TEST_ONLY，不能继承为已确认真机配置。
- 真机配置必须显式填写地址、方法、路径、时间基准、单位/比例与鉴权；未知单位保留原文但不得产生合格判断。lineId必须显式绑定任务，不按名称/工单号猜盘。PITCH不进入WIRE_GAP。
- 不根据controlStatus猜质量或执行控制；不从宽度倒算缺失搭盖率；图片地址随原始记录保留，不伪造图片或自动访问任意地址。
- 供应商JSON含小数，完整原文以JSON文本保存，避免违反平台raw整数/十进制字符串约束。稳定来源ID、逐条回执、失败保留、冲突不覆盖。
