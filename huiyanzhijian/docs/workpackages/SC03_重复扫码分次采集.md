# SC03 重复扫码分次采集

2026-11-02；B类M02/M09/M10流程重构；已实现、已部署、自测通过待用户验收，未冻结。

## 1 范围与规则（已完成）

- 不圆度模拟任务及护套辅助数据：同一任务条码允许再次扫描。每次独立扫码生成独立执行任务，按第1次、第2次采集展示，同盘、同工单并关联来源任务；旧任务、绑定、数据与规则快照不覆盖。
- 首扫CREATED沿用原任务；重扫RUNNING先结束当前执行再创建新执行；重扫ENDED创建新执行。同一命令重试只返回原回执；取消、错设备、失效归属码仍拒绝。
- 新执行沿用扫码任务冻结规则和当前业务归属，独立绑定与时间范围；原送料停止，新送料绑定新任务；历史补传仍按旧身份。
- 允许修改M02扫码/任务API、M09生命周期、M10任务展示、模拟器扫码文案及必要请求去重、测试和文档。保留EDGE11开机主屏等待扫码。无算法、阈值及图片功能变化。

## 2 存储与展示（已完成）

复用inspection_task独立任务、task_device_binding和command_receipt；追加执行的context_snapshot.scan_execution保存来源任务ID/编号和采集序号；无表结构迁移。工单和任务列表分行，详情保留来源链接，历史与统计按独立任务读取。同盘汇总继续使用现有盘号关系。

## 3 验收标准（自测通过，待用户验收）

1. 已结束码可再次扫描；旧数据不变，新任务RUNNING且新绑定，页面两行可独立回看。
2. 当前同码重扫创建下一次；请求重试不多建；切换失败回滚，取消/错设备/旧归属拒绝。
3. 断网重试与重启不重复执行；旧样本补传不串入新执行。
4. 真实PG/API、Go与前端回归、真实浏览器分次展示，记录验证结果后仅更新相关服务。
