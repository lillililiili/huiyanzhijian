# SIM07 线缆正常基准与异常值自定义

2026-10-27｜B类模拟器页面增强｜M10前端与模拟器本地模型｜已部署4196；静态JS语法、TypeScript镜像构建和容器健康通过，功能/浏览器验收待用户确认。

范围：4196线缆编辑弹窗内编辑五项正常基准值；为三项检测配置匹配的区段异常物理值与默认值、说明换算；保存仍使用SIM02版本追加与过料快照。修改`tools/simulator/web/`及契约/台账；无平台API、PostgreSQL、SIM设备权限或真机改动。

默认值：铜带宽度20mm、搭盖宽度2.5mm、铜丝间隙1.25mm、X向直径40mm、Y向直径40mm。缺陷创建默认从0m起、长1m：搭盖宽度异常1mm、铜丝间隙异常4mm、不圆度异常段Y向直径48mm（X向沿用线缆基准值）。全部可修改；改检测项时自动载入对应异常类型、默认问题描述和值。相同检测项区段不允许重叠；新增区段自动选择该检测项下一个未占用位置，无法安排时提示调整。

换算展示：搭盖率=`搭盖宽度÷铜带宽度×100%`；间隙直接为mm；当前兼容测试不圆度=`200×|X−Y|÷(X+Y)%`。默认值组合下，缺陷搭盖值对应5%（默认设备下限10%），间隙4mm（默认上限3mm），X=40/Y=48mm对应18.181818%（默认上限8%）；可在设备模拟设置自定义这些测试界限。换算仅帮助理解模拟读数，不是生产质量结论。正常参数在缺陷区段外生效，区段内只替换该检测项对应的物理量；数据库保存新SQLite模型版本，旧送料快照不变。

验收：新建和编辑都能读取并修改五项有单位参数；输入约束、保存原因及服务端模型校验有效；每项缺陷预填对应值、能编辑、会实际改变设备模拟读数；按指定值换算预览正确；保存刷新后能回读版本，旧记录快照保持原样。只重建并更新4196，保留模拟器SQLite卷；记录是否部署及人工初验。
