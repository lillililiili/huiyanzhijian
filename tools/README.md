# 开发与维护工具

后续放构建辅助、隔离夹具、协议模拟与目录校验脚本。工具不包含正式业务规则，不默认连接生产设备或数据库。

后续独立数据模拟器规划路径为tools/simulator/，先完成统一设备上传契约，再实现生成、传输、场景与运行状态；不直写平台数据库，不嵌入正式页面。详见 [第14份第5节](../huiyanzhijian/docs/14_开发架构与技术选型规划.md#5-为数据模拟器预留稳定接入边界)。目前尚无模拟器代码。

模拟器开发前必读 [第15份统一接入契约](../huiyanzhijian/docs/15_模拟器与真实设备统一接入契约.md) 与contracts/devices/v1。ING01已提供字段、回执及异常样例；模拟器本身尚未编写。
