# SIM06 设备运行与启用状态（2026-10-27）

设备模拟卡片分别显示平台“已启用/已停用”配置与当前运行状态。运行状态区分待命、任务占用、送料中、暂停、停止及同步异常；查看送料进入对应运行，查看占用任务进入主平台。停止送料不等于结束平台任务。完成历史里的旧运行标记不会占用设备。仅显示授权模拟设备，不代表真实设备心跳或硬件状态。

平台状态约5秒同步，本地执行默认1秒刷新；断连时明确显示未同步。此次只需更新模拟器容器，无平台API或数据库迁移。见[状态契约](../../contracts/simulator/SIM06-device-status.md)。

# SIM05 主平台目录同步（2026-10-27）

当前线缆目录直接读取主平台工单、主盘、规格和授权模拟任务；设备目录读取凭据授权的SIMULATED设备。当前部署同步34盘、3设备。新增线缆及设备资料在主平台维护；此处为同一内部ID配置缺陷与模拟参数，不再另建同名档案。目录每5秒读取，也可手动刷新；搜索和待检测/已检测为服务端分页。新主平台设备仍须纳入模拟设备凭据授权范围，不自动扩大权限。

“已检测”指授权模拟任务已有平台接收的STORED记录，与预设版本是否跑完、业务任务是否结束、质量是否合格分别展示。仅显示本厂无REAL任务的主盘（包括尚未分配任务的线缆）；同盘成员归一显示。旧SIM04本地独立模型和运行快照保留，不能按名称自动合并。

使用：在4181登记线缆、分配并开始任务 → 4196线缆页配置该盘预设 → 设备页配置对应设备模拟参数 → 送料页明确选择该盘、设备、任务 → 开始送料 → 4181历史页查询同一任务。AUTO模式仍需平台自动发现配置，并明确选择已有CREATED/RUNNING任务，不自动创建另一盘身份。运行与版本仍保存在模拟器SQLite，检测通过API写入平台PostgreSQL；停止模拟器不删除已收数据。测试界限不替代批准生产规则。

新增可选环境变量`SIM_PLATFORM_URL`指定浏览器可访问的主平台地址；未设置时沿用当前浏览器主机名、4181端口。`SIM_API_URL`仍是容器访问后端的地址，两者不同。无需改账号密码或数据库表。升级需同时更新后端与模拟器镜像，命令和回滚见[SIM05契约](../../contracts/simulator/SIM05-platform-catalog.md)。

# 独立设备输入模拟器

## 独立Web系统（SIMWEB01）

控制台：http://127.0.0.1:4196 。独立账号为 `admin`，当前本机密码见根目录 `runtime/simulator/access.json`，不要提交或分享该文件。后端仍为 http://127.0.0.1:4192 的API服务。

在项目根目录运行：

```powershell
node tools/simulator.mjs init    # 首次生成本机配置、构建并启动；不自动生成检测数据
node tools/simulator.mjs start   # 使用已有镜像启动
node tools/simulator.mjs status
node tools/simulator.mjs logs
node tools/simulator.mjs stop    # 保留队列卷与历史
```

独立部署文件为本目录 `compose.yaml`，只定义模拟器服务和持久卷，不包含后端或数据库，不依赖后端Compose网络。等价构建启动命令：

```powershell
docker compose --env-file runtime/simulator/simulator.env -f tools/simulator/compose.yaml build
docker compose --env-file runtime/simulator/simulator.env -f tools/simulator/compose.yaml up -d --wait
```

`init` 使用本机已有Node 22镜像，不自动拉取；首次从B1本机配置读取SIMULATED设备凭据，之后运行仅依赖独立配置。也可参照 `.env.example` 手工配置 `runtime/simulator/simulator.env`，设置 `SIM_API_URL`、`SIM_DEVICE_TOKEN`、`SIM_WEB_PASSWORD`。当前通过 `host.docker.internal:4192` 连接后端；换机器时改为可达的API地址，不配置数据库连接。默认只监听本机；远程开放、HTTPS及组织账号接入另行部署设计。

Web支持三项指标的场景、数量、间隔、种子配置，以及开始、暂停、继续、停止、补传、原键重放、真实样本/回执/趋势/日志查询。绑定模式由平台人员准备并开始任务；自动模式发送设备ENTER/EXIT，由平台按已启用的自动发现配置建立任务，模拟器不调用人员建单接口。详见[本轮验收指南](../../docs/workpackages/SIMWEB01_独立模拟器Web系统.md)。

Web重启后需重新登录，不自动恢复采样；历史和待传保留，可人工继续或补传。同一设备仅允许一个采集进程。Web队列为自己的命名卷，不自动迁移原B1 CLI队列，也不要同时对同一设备从两个独立队列采样。单实例部署；历史列表显示最近100次，单次样本每页50条，执行日志显示最近50项。启动健康检查只说明Web可用，上游状态以页面为准。

## 兼容CLI

B1设备契约1.0，三项指标，SIMULATED来源。只调用设备HTTP API，不直接访问PostgreSQL，不创建工单/盘号/任务。平台人员先开始任务，模拟器取得/确认绑定后才生成输入。

根目录运行`node tools/b1.mjs sim status`查询持久队列；`node tools/b1.mjs sim run --device HY-DG-01 --run demo-001 --count 100 --interval-ms 50 --scenario mixed`模拟搭盖率。详细三指标、重放、停止与恢复步骤见[验收指南](../../docs/workpackages/B1_后端数据库与设备模拟器.md)。

支持run/status/pause/resume/stop/drain/replay；正常、边界、超限、无效与mixed；同run持久化capture_session、样本ID、完整载荷和收据。HTTP未知结果保留原键，退避重试；永久错误停止并保留。新的数据流使用新run名，不能复用旧run改变任务或场景。

SQLite使用WAL与FULL同步，命名卷持久化，与服务端业务库职责分开。sim_run保存场景/种子/分配和生成进度；sample保存原文/收据/传输状态；delivery_attempt保存传输诊断；producer_lease防止同设备同时有两个生成进程。暂停只停新采样，补传继续；停止保留队列。超过等待期仍有待传退出码2。

最小间隔50ms、单次最多100000条，队列待传上限100000，磁盘不足16MiB停止采样。它是开发测试工具，Node内置SQLite仍标实验接口；不作为真机软件或采样性能承诺。不模拟真实编码器精度、光学图像或全周测量公式。

本地编译`npm ci --ignore-scripts`后`npm run build`；环境API_URL、DEVICE_TOKEN或ACCESS_FILE、SIM_DB。默认路径按本目录运行解析；优先使用根目录b1工具运行容器以避免目录差异。

## SIM02 双模块工作流

“线缆模拟”独立保存正常几何量、缺陷名称/起点/长度/异常物理量；“设备模拟”独立保存检测项、步长、速度与测试界限。“过料检测”选择两个版本并冻结，设备读取当前位置几何量后计算数值和源判定，再经既有设备接口上传。完整预设清单不上传业务平台。旧场景与手动事件保留在“接口诊断”。

自动模式要求平台已启用并配置自动发现；绑定模式要求已有运行任务。短缺陷可能因采样间隔漏检，不伪造检出。模型和过料快照保存在SQLite的model_revision/model_pass，业务采样在PostgreSQL。重启不自动采样，待传/历史保留；强停后现有租约可能需要等待30秒。

本功能是数值/几何模拟，不含图像/AI或真机精度。OVALITY沿用1.0百分比测试公式并保存mm原值，不能视作生产标准。详见[契约](../../contracts/simulator/SIM02-cable-device.md)和[验收记录](../../docs/workpackages/SIM02_线缆与设备双模块模拟.md)。

## SIM03 实时送料与历史

运行记录默认收起，点击标题展开；实时送料区始终可见，桌面采集中吸顶。选择当前运行后可暂停/继续/停止，并在运行或暂停时应用新送料速度。速度仅影响后续采样间隔，保存为SQLite版本，不改冻结检测模型和已有数据；实际节拍受接口响应影响。

采集进程在间隔等待中响应控制；暂停/停止提交后禁止生成新样本，已发送请求仍可返回回执。停止保留进度，不能代替业务任务完工。进程确认关闭后只释放其自身租约，继续从原序号恢复。刷新频率0.5/1/2/5秒，仅保存当前标签会话偏好；断服显示状态未同步。

# SIM07 线缆参数与缺陷自定义

4196线缆新建/编辑可直接填写正常基准值：铜带宽度20mm、搭盖宽度2.5mm、铜丝间隙1.25mm、X/Y直径40mm；每项默认值可编辑，保存追加线缆模型版本。缺陷预设提供匹配的物理量默认值、区段和公式说明：搭盖宽度1mm、间隙4mm、异常Y向直径48mm，默认区段从0m起长1m。换算只作模拟读数说明；历史送料保持原冻结版本。
