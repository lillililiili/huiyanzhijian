# 慧眼智检 · 线缆质量管控平台

HTML、CSS、原生 JavaScript 实现的 27 页本地交互原型。适用对象为 **35–220 kV 高压电缆**，仅包含金属屏蔽搭盖率、铜丝屏蔽相邻铜丝间隙、电缆不圆度三项检测。

## 启动

在此目录打开终端，使用项目自带的 Node.js 静态服务运行：

```powershell
node server.cjs
```

浏览器打开 [http://127.0.0.1:4174](http://127.0.0.1:4174)。服务默认仅监听本机；可使用 `node server.cjs 4175` 指定其他端口。

也可以使用 Python 备用服务：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

备用服务地址为 [http://127.0.0.1:4173](http://127.0.0.1:4173)。没有 `python` 命令时，可以使用本机已安装的 Python 路径：

```powershell
& 'C:\Users\19221\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -m http.server 4173 --bind 127.0.0.1
```

无需安装 npm 依赖、无需构建。图表库、图标、图片均随项目保存，页面运行不依赖 CDN。HTTP 服务仅负责读取静态文件。

| 演示账号 | 身份 | 密码 |
| --- | --- | --- |
| `admin` | 系统管理员 | 任意不少于 4 位的字符，例如 `1234` |
| `quality` | 质量管理员 | 同上 |
| `viewer` | 只读观察员 | 同上 |

登录为本地角色演示，不向服务器发送账号密码。用户、设备接入与 MES 配置都是模拟数据；本项目不连接生产设备或 MES。

## 推荐演示流程

1. 以 `admin` 登录，工作台查看三项趋势、当前任务及待复核事项。
2. 进入搭盖率检测页，在曲线上定位 **14:06、9.20%** 的异常点，查看同一记录的量测示意、规则快照和同步状态。切换时间／米数横轴。
3. 从报警列表进入 `AL20261009001`，填写复核说明，进入处理中或完成处置。当前值恢复正常不会自动关闭这条报警。
4. 打开任务 `T20261009001`，回放下一条记录、预览阶段报告或结束任务。任务完成且关联报警已复核后，可生成最终报告。
5. 原任务结束后，新建任务并选择兼容规格、检测项目、执行设备和配方。开始检测，生成若干条演示记录后完成任务。设备同一时间只执行一个任务。
6. 通过盘号追溯将任务、原始数据、异常处置和报告关联起来；历史查询导出 CSV，报告预览后打印或由浏览器另存 PDF。
7. 在系统设置切换 MES 失败场景，进入同步监控查看失败记录；切换正常场景后重试，同一记录不会重复生成。

## 数据规则

- 初始演示时间固定为 `2026-10-09 14:30:00`，当前窗口为 `14:01–14:30`。操作回放沿演示时间轴推进；审计日志另存真实操作时间。
- 初始包含 12 个任务（3 个检测中、9 个已完成）、3 台在线设备、6 个规格、90 条当前有效记录和 108 条此前任务记录。
- 当前值分别为 `12.36%`、`1.52 mm`、`4.37%`；当前窗口 88 条符合阈值、2 条超限、1 条待复核。历史超限原始记录不会因最新值恢复而被覆盖。
- 演示判定为搭盖率 `≥10%`、平均铜丝间隙 `≤3 mm`、不圆度 `≤8%`，边界值算符合。配方修改生成新版本，只影响之后创建的任务。
- 每条记录保留任务、工单、盘号、设备、时间、米数、图像及规则快照。数据有效性、数值判定、任务状态、报警处置、MES 确认分别保存。
- 无效数据以 `null` 保存，不按 0 处理，也不进入有效数据统计。不适用项目不参与任务创建与完成条件。
- 铜丝量测示意保留四处局部间隙及其平均值；不圆度为设备输出，X / Y 外径仅为辅助数据，不推导未经确认的公式或全周截面。
- 报告保存任务、规格、设备、原始记录、报警、统计和模板的深度快照，之后修改配置或补录不会重写既有报告。运行中任务生成阶段报告。
- 补录绑定已有任务，支持 `dg / jx / by`。CSV 导入检查时间、米数、量测值、任务关联和重复数据；错误行提供行号与原因。已完成任务可补录，原有报告保持不变。
- 切回正常场景恢复当前连接，保留已发生的异常和同步失败历史；失败同步可单独重试。

## 本地保存与恢复

业务数据保存在浏览器 `localStorage` 的 `huiyan-native-prototype:v1`，登录会话使用 `sessionStorage` 的 `hy-session-v1`。数据按浏览器和访问地址隔离；`localhost` 与 `127.0.0.1` 是不同的存储来源。存储不可用时会在内存继续演示。

系统设置提供“恢复初始演示数据”操作，可重置任务、配置与处理记录。无需修改源文件或清除浏览器其他站点数据。

## 结构与素材

```text
index.html                     单入口页面
server.cjs                     无依赖本地静态预览服务（默认端口 4174）
css/                           视觉样式与响应式布局
js/data.js                     本地数据仓库与领域规则
js/ui.js                       公共组件、图表与量测叠加
js/pages-core.js               工作台、检测、任务、规格、历史、导入
js/pages-management.js         报警、报告、配置、设备、系统管理
js/app.js                      登录、权限、导航、交互分发
assets/images/                 原 Logo / 设备裁图与 AI 生成图片
assets/references/             用户提供的十张原型参考图
assets/icons/                  Tabler outline SVG 本地图标
assets/vendor/                 ECharts、图标来源包与许可证
assets/manifest.json           来源、裁切坐标、版本、许可证、文件哈希
tests/domain.test.js           领域规则测试
qa/                            验收材料
```

原 Logo、登录设备组和三台设备图均从用户参考图无损裁切，保留原始像素。登录背景、铜带、铜丝、不圆度示意和三项专题图标由生图模型生成；量测文字、数值和标线由界面独立绘制。参考图第 3、4 张相同；页面数量按 27 页计划实现。

第三方依赖：Apache ECharts **6.0.0 / Apache-2.0**，Tabler Icons **3.35.0 / MIT**。完整许可证与 ECharts NOTICE 保存在 `assets/vendor/`。

## 验证

```powershell

```

共 48 项检查，覆盖初始跨实体一致性、阈值边界、空值统计、规格适用性、任务全流程、离线、人工复核、规则版本、报告快照、MES 幂等、CSV 校验、历史补录、本地存储、角色审计和窄屏导航键盘焦点。

界面验收基准为 1920×1080，同时检查 1440×900、1366×768；窄屏使用导航抽屉和横向滚动表格。浏览器打印可保存 PDF，CSV 导出生成真实本地文件。
