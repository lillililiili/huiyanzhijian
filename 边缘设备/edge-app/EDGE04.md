# EDGE04 双测径仪检测（1.3.0）

2026-10-30；用户调整边缘端为圆整度与护套厚度两项。工艺展示：线缆出 → 测径仪A → 线缆挤出机 → 测径仪B → 线缆入。

## 计算与显示

- A必须提供X/Y两个有效且大于0的直径。A均值=(X+Y)/2；圆整度=min(X,Y)/max(X,Y)，最大1、越接近1越圆，单位1。仪器平均寄存器原值仍保存在average字段，不覆盖它；新mean及axis_mean_mm为轴算术均值。
- B输入values数组长度1为X，长度2为X/Y；单轴均值=X、双轴均值=(X+Y)/2。缺失Y不补0，存在但无效的Y使本条无效，不降级单轴。B不产生圆整度，也不显示平均值曲线。
- 按用户原文计算护套厚度=A均值−B均值，保留符号、不除2、不取绝对值。该公式是本轮明确实现口径；其物理含义/工艺前后方向已询问，未收到新指示前保持原文。没有护套合格阈值，不给PASS/FAIL结论。
- 实时以当前已到达的另一台仪器记录中采样时间最近者配对，必须同一run、同一来源环境。默认窗口100ms，可在设置中改1～5000ms；这是工程时间窗，不是产品合格标准。相同窗口内最近记录无效则不借用更远的有效值。
- 尚未补偿两仪器间距和线速，不宣称同一材料截面；状态明确“未补偿运行距离”。允许同一对侧记录被邻近时间的多次采样引用，配对不是一对一物料追踪。已保存配对不因晚到数据重算。
- 等待/无效/超窗时厚度为空。实时页面超过3秒未收到新数据则不将厚度显示为当前值；暂停/结束显示末次读数。原始样本不重写。

## 接入

A原Modbus RTU/TCP和模拟器→边缘→中心链路保留。现有4196仅提供A数据；没有B输入时不编造B或护套厚度。B真实寄存器协议尚未确认，因此本版本实现经过机器认证的结构化轴值接口，未擅自套用A的寄存器。未添加B真实串口适配、未修改4196模拟器。

新增 `POST /edge/v1/gauges`，沿用EDGE_INBOUND_TOKEN的Bearer认证，JSON请求：

```json
{"runId":"当前边缘run.id","recordId":"来源稳定记录ID","gauge":"B","at":"2026-10-30T08:00:00.000000000Z","values":[40.0],"status":"VALID","source":"SIMULATED"}
```

上述数值仅字段示例，不是种子数据或生产阈值；本轮未发送。双轴时values=[X,Y]。status可VALID/INVALID/MISSING；无效可空数组，轴原始输入仍保存。at必须RFC3339带时区，recordId在源端首次产生时固定；相同run/gauge/recordId同内容幂等，异内容拒收。

接口必须绑定当前RUNNING本盘；需先开始、扫码，使用GET /edge/v1/status返回的run.id/source。来源必须严格匹配：模拟扫码run为SIMULATED，物理Modbus run为MODBUS，A选“轴值数据接口”的独立本盘为DEVICE_INPUT。不自动改变来源、不跨盘配对，暂停/结束拒绝新记录；已经持久化的同ID重试可返回原回执。

A需要通过此接口接入时，应结束本盘，将A连接方式设为“轴值数据接口”，使用原orders接口登记工单后扫码启动。模拟器已有A流不能再混入此接口的A记录。B在A仍使用原Modbus或模拟器时可独立输入。

本机设置仍通过CSRF保护，远程轴值接口只通过机器凭据；凭据不得交给页面。没有自动发现B寄存器、PLC写控制或远程升级行为。

## 保存与中心边界

Sample新增gauge/mean/inputValues/sheath；旧记录没有gauge按A读取，不补造B/厚度。sheath保存方法版本、A/B记录ID、两端时间/均值、时间差、配对窗、状态及带符号结果。原始样本和来源去重索引在同一bbolt事务提交，之后才更新UI。

InfluxDB继续2.9.1：新数据增加gauge tag、axis_mean_mm、sheath_value_mm和配对字段；原游标/旧时序不重置。CSV新增测径仪、A均值、护套结果及完整配对来源。历史表中B不显示A圆整度或均值结果，CSV保留参与计算的均值供追溯。

中心现有OVALITY请求只上传原A圆整度/旧百分比快照值；B及护套结果本轮保存在边缘和InfluxDB，不写入中心OVALITY。未扩中心指标枚举、数据库、报告、模拟器或其他检测项。预留edge.v1批次通道尚未启用，生产中心新增护套指标另需契约。

## 安装与限制

安装包huiyan-edge-1.3.0-ubuntu-amd64-arm64.tar.gz，升级保留数据库、InfluxDB凭据、原时序数据和中心待传。部署前备份完整本应用。Webtop使用install-webtop.sh；普通Ubuntu使用install.sh，详见README。

按此前用户要求，构建打包部署，不执行功能/浏览器/吞吐/HW测试。界面交互、六线可读性、真实B输入、配对效果与现场厚度意义均待用户验收，未冻结。旧版本性能结果不能替代本版本结论。
