B 与 A 均读取同一组六寄存器，按状态字轴数识别单轴/双轴。双轴错误不会降级成单轴。未启用时可使用认证轴值接口输入一个 X 或两个 X/Y 值。模拟盘仅接收模拟来源，不启动真实 B 采集。

寄存器与单位设置

连续读取6个保持寄存器：状态、平均直径、X直径、X位置偏移、Y直径、Y位置偏移。默认地址512 = 0x0200，除数1000，与参考程序一致。

通信参数须与仪器一致。软件采样周期不等于仪器的有效刷新周期；9600波特率不支持50次/秒完整查询。
